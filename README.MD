 📌 What is Shell Scripting?

**Shell Scripting** is the process of writing a series of Linux commands in a file and executing them together.

Shell scripts are commonly used for:

* ⚙️ Task Automation
* 🐧 Linux System Administration
* 📊 System Monitoring
* 📁 File and Directory Management
* 💾 Backup Automation
* 🚀 Deployment Automation
* 🔧 DevOps Operations

🎯 Why Learn Shell Scripting?

Shell scripting helps reduce repetitive manual tasks and makes common Linux operations faster and easier.

In DevOps, Shell Scripts are useful for **automation, server management, deployments, monitoring, configuration management, and CI/CD workflows**.

✍️ How to Create a Shell Script

1️⃣ Create a file

touch script.sh

2️⃣ Add the Bash shebang
 #!/bin/bash

3️⃣ Write your commands

Example:
#!/bin/bash

echo "Hello from Shell Script"
hostname
date


▶️ How to Run a Shell Script

First, give the script execute permission:

chmod +x script.sh

Then execute it:
./script.sh

You can also run it using Bash:
bash script.sh
